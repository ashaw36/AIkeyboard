【第一步】打开Android Studio
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 启动Android Studio
2. 点击 [Open] 按钮
3. 选择文件夹: D:\百宝箱\AIKeyboard
4. 等待Gradle同步完成 (约3-5分钟)


【第二步】构建APK安装包
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 点击菜单: Build → Build Bundle(s) / APK(s) → Build APK(s)
2. 等待构建完成 (约2分钟)
3. 看到提示: "APK(s) generated successfully"
4. 点击 [locate] 查看APK位置

APK文件路径:
D:\百宝箱\AIKeyboard\app\build\outputs\apk\debug\app-debug.apk


【第三步】安装到小米手机
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方法A: USB连接安装 (推荐)
────────────────────────
1. 开启USB调试:
   手机设置 → 我的设备 → 全部参数 → 连续点击"MIUI版本"7次
   手机设置 → 更多设置 → 开发者选项 → USB调试 (开启)

2. 连接手机到电脑 (USB线)

3. 手机上点击"允许USB调试"

4. 在Android Studio中点击绿色 ▶ 运行按钮

5. 选择你的小米手机，应用会自动安装

方法B: 手动安装 (简单)
────────────────────────
1. 将 app-debug.apk 复制到手机
   (通过微信/QQ发送文件，或蓝牙传输)

2. 在手机上打开"文件管理"

3. 找到 app-debug.apk 文件

4. 点击文件，选择"安装"

5. 如提示"未知来源"，允许安装


【第四步】配置键盘
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 启用键盘:
   ┌─────────────────────────────────┐
   │ 1) 打开"AI键盘"应用              │
   │ 2) 点击"点击启用键盘"按钮        │
   │ 3) 在系统设置中勾选"AI键盘"      │
   │ 4) 点击"确定"允许                │
   └─────────────────────────────────┘

2. 配置API:
   ┌─────────────────────────────────┐
   │ API Key: [填写DeepSeek的API Key] │
   │ API地址: https://api.deepseek.com│
   │ 模型: deepseek-chat              │
   └─────────────────────────────────┘

3. 测试连接:
   点击"测试连接"按钮，看到"连接成功 ✓"

4. 切换输入法:
   ┌─────────────────────────────────┐
   │ 1) 打开任意应用 (微信/备忘录)    │
   │ 2) 点击输入框                    │
   │ 3) 长按输入框                    │
   │ 4) 选择"输入法" → "AI键盘"      │
   └─────────────────────────────────┘


【获取DeepSeek API Key】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 访问: https://platform.deepseek.com/

2. 注册/登录账号

3. 进入"API Keys"页面

4. 点击"创建新密钥"

5. 复制生成的Key (格式: sk-xxxxxxxx...)

6. 粘贴到AI键盘的设置中

提示: DeepSeek提供免费额度，足够日常使用！

【常见问题】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Gradle同步失败？
A: File → Invalidate Caches → Restart

Q: 构建失败？
A: Build → Clean Project，然后重新构建

Q: 手机连接不上？
A: 确认USB调试已开启，尝试更换USB端口

Q: API连接失败？
A: 检查API Key是否正确，手机网络是否正常

Q: 键盘无法启用？
A: 系统设置 → 语言和输入法 → 虚拟键盘 → 启用AI键盘
