═══════════════════════════════════════════════════════
            📋 获取APK的3步操作清单
═══════════════════════════════════════════════════════

⏱️ 总耗时：约15分钟


┌─────────────────────────────────────────────────────┐
│                                                     │
│  第1步：上传代码到GitHub                            │
│  ────────────────────────────────────────────────  │
│                                                     │
│  方式A：GitHub Desktop（推荐，图形界面）            │
│  1. 下载：https://desktop.github.com               │
│  2. 安装并登录                                      │
│  3. File → Add Local Repository                    │
│  4. 选择：D:\百宝箱\AIKeyboard                      │
│  5. Publish repository                             │
│                                                     │
│  方式B：Git命令行                                   │
│  1. 下载Git：https://git-scm.com/download/win      │
│  2. 在项目文件夹右键 → Git Bash Here               │
│  3. 执行命令（见下方）                              │
│                                                     │
└─────────────────────────────────────────────────────┘

  Git命令：
  ┌───────────────────────────────────────────────────┐
  │ git init                                          │
  │ git add .                                         │
  │ git commit -m "Initial commit"                    │
  │ git remote add origin <你的仓库地址>              │
  │ git push -u origin master                         │
  └───────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────┐
│                                                     │
│  第2步：等待GitHub自动构建APK                       │
│  ────────────────────────────────────────────────  │
│                                                     │
│  • 代码上传后自动开始                               │
│  • 约10分钟完成                                     │
│  • 查看进度：GitHub仓库 → Actions标签               │
│                                                     │
│  状态标识：                                         │
│    🟡 = 正在构建中                                  │
│    ✅ = 构建成功                                    │
│    ❌ = 构建失败（很少见）                          │
│                                                     │
└─────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────┐
│                                                     │
│  第3步：下载APK                                     │
│  ────────────────────────────────────────────────  │
│                                                     │
│  1. GitHub仓库 → Actions                            │
│  2. 点击显示 ✅ 的构建                              │
│  3. 滚动到页面底部                                  │
│  4. 找到"Artifacts"部分                             │
│  5. 点击"app-debug"下载                             │
│  6. 解压zip文件，得到app-debug.apk                  │
│                                                     │
└─────────────────────────────────────────────────────┘


═══════════════════════════════════════════════════════
            📱 安装APK到手机
═══════════════════════════════════════════════════════

1. 发送到手机
   • 微信文件传输助手
   • QQ我的电脑
   • 或其他方式

2. 在手机上打开APK

3. 允许"未知来源"安装
   （小米：设置→隐私保护→安装未知应用）

4. 点击安装

5. 打开"AI键盘"应用配置


═══════════════════════════════════════════════════════
            🔄 以后更新代码
═══════════════════════════════════════════════════════

GitHub Desktop：
  1. 打开GitHub Desktop
  2. 输入提交说明
  3. 点击"Commit to master"
  4. 点击"Push origin"

Git命令行：
  git add .
  git commit -m "更新说明"
  git push

→ GitHub自动构建新APK
