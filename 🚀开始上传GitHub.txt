📋 GitHub Actions工作流说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

文件位置：.github/workflows/build-apk.yml

触发条件：
  • 推送代码到master分支
  • 创建Pull Request
  • 手动触发（在Actions页面）

构建步骤：
  1. 检出代码
  2. 设置Java 17环境
  3. 缓存Gradle依赖
  4. 授予gradlew执行权限
  5. 执行构建（./gradlew assembleDebug）
  6. 上传APK到Artifacts

构建时间：
  • 首次：约8-10分钟
  • 后续（有缓存）：约3-5分钟

⚠️ 注意事项

1. README文件
   当前有两个README：
   • README.md（本地技术文档）
   • README_GITHUB.md（GitHub展示用）

   推送前建议：
   • 删除或重命名原README.md
   • 将README_GITHUB.md重命名为README.md

2. API Key安全
   • 不要把API Key写在代码里
   • 不要推送包含API Key的文件
   • 使用应用内设置输入

3. 构建类型
   • Debug版本：用于测试，无需签名
   • Release版本：用于发布，需要签名文件

4. 公开/私有仓库
   • 公开仓库：任何人可见，无限构建
   • 私有仓库：只有你可见，2000分钟/月
